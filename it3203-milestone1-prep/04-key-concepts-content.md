# Key Concepts Page

Explain 5–7 concepts. Using seven gives the page enough substance without becoming repetitive.

## 1. HTTP Method
A method communicates the action a client wants to perform. Common methods include GET, POST, PUT, PATCH, and DELETE. The method helps the server decide how to process a request.

## 2. Status Code
A status code summarizes the result of an HTTP request. Codes in different ranges communicate different categories of outcomes. For example, 200 indicates success, 404 indicates that a resource was not found, and 500 indicates a server-side problem.

## 3. Header
Headers contain metadata associated with a request or response. They can describe content type, accepted formats, caching rules, cookies, authorization, compression, and security-related information.

## 4. Request and Response
HTTP communication uses a request-response model. The client asks for a resource or action, and the server returns the result. This model is the core idea behind HTTP even though the protocol has changed significantly over time.

## 5. HTTPS / TLS
HTTPS protects HTTP communication with TLS. TLS provides encryption and authentication so that sensitive information is more difficult for third parties to read or alter while it travels across a network.

## 6. Caching
Caching allows clients, browsers, proxies, and other systems to reuse previously retrieved resources when appropriate. Good caching can reduce network traffic and improve performance.

## 7. QUIC and HTTP/3
QUIC is the transport protocol used by HTTP/3. It is built on UDP and provides secure, multiplexed communication. QUIC can also support connection migration, which is useful when a device changes networks.

## Page title
HTTP: The Protocol That Carries the Web

## Intro / abstract
HTTP, or Hypertext Transfer Protocol, is one of the core communication technologies of the World Wide Web. It defines how clients such as browsers and mobile applications request resources and how servers respond with webpages, images, files, API data, and other content. Although the web has changed dramatically since its early years, HTTP still uses the same basic request-and-response idea while newer versions have improved speed, reliability, security, and efficiency.

This project explains how HTTP works, how the protocol evolved from HTTP/0.9 through HTTP/3, and why concepts such as methods, headers, status codes, caching, HTTPS, and QUIC are important to modern web development.

## Key terms
- **HTTP:** Hypertext Transfer Protocol, the communication protocol used to exchange web resources.
- **Client:** A device or program, such as a browser, that sends a request.
- **Server:** A system that receives a request and returns a response.
- **Request:** A message sent by a client asking for a resource or action.
- **Response:** The server's reply containing a status, headers, and often content.

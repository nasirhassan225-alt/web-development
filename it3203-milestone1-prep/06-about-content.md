# About Page

## About Nasir Hassan
Nasir Hassan is an Information Technology student at Kennesaw State University with interests in computer systems, infrastructure, networking, and modern web technology. His technical studies include web development and data communications and networking.

For this IT 3203 project, Nasir is researching HTTP and its role in moving information across the World Wide Web.

## About this project
This website is being developed as part of the IT 3203 Web Development course. The project is designed to present research through a multi-page website while applying introductory HTML and CSS skills.

Milestone #1 focuses on the site's basic structure, informational content, navigation, HTML elements, and CSS styling. Later milestones expand the project with JavaScript and responsive/mobile design.

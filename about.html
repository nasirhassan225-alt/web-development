Professional Interests

My technology interests include systems, networking, infrastructure, web technologies, and the way different technical layers work together. HTTP is a useful research topic because it connects application behavior to browsers, servers, APIs, security, content delivery, and network performance.

Project Purpose

This site was created for IT 3203 Project Milestone #1. It transforms my Assignment #1 research on HTTP into a multi-page website built with HTML and one shared CSS file. The project demonstrates semantic HTML structure, navigation, lists, tables, images, CSS selectors, CSS Grid/Flexbox, consistent styling, and organized technical content.

What I Practiced

  • Organizing one research topic across several linked web pages.
  • Using semantic HTML elements for structure and accessibility.
  • Creating a consistent navigation menu and site footer.
  • Using one external stylesheet to control layout and appearance.
  • Applying element, class, and ID selectors.
  • Using CSS Grid/Flexbox, hover effects, spacing, borders, colors, and font settings.
  • Publishing a working website with GitHub Pages.

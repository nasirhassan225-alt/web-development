Seven Key HTTP Concepts

These concepts connect the protocol's basic vocabulary to real browser and server behavior.

1. HTTP Request

A request is the message a client sends to a server. Example: GET /index.html asks for a resource.

2. HTTP Response

A response is the server's answer. It includes a status, headers, and sometimes a body containing HTML, JSON, an image, or other data.

3. HTTP Method

A method describes the requested action. Common examples include GET, POST, PUT, PATCH, and DELETE.

4. Status Code

A status code summarizes the result. 200 means success, 404 means not found, and 500 indicates a server-side failure.

5. HTTP Header

A header carries metadata. Content-Type identifies the representation, while Cache-Control can guide caching behavior.

6. HTTPS / TLS

HTTPS uses TLS to encrypt traffic and authenticate the server. It is the normal secure form of HTTP on today's public web.

7. QUIC

QUIC is the secure transport used by HTTP/3. It runs over UDP and provides streams, reliability, congestion control, and connection features.

How the Concepts Connect

A browser can send a GET request over HTTPS. The request contains headers. The server returns an HTTP response with a status code. If the connection uses HTTP/3, the exchange is carried over QUIC. These terms describe different layers of the same interaction rather than unrelated technologies.

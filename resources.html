References & Resources Page

References and Learning Resources

Primary standards and trusted educational resources used to build the HTTP research project.

Core Standards

  1. RFC 9110 — HTTP Semantics: Defines shared HTTP semantics including methods, status codes, fields, and message meaning.
  2. RFC 9111 — HTTP Caching: Defines caching behavior shared across HTTP versions.
  3. RFC 9112 — HTTP/1.1: Defines the HTTP/1.1 message syntax and connection handling.
  4. RFC 9113 — HTTP/2: Defines HTTP/2 framing, streams, and protocol behavior.
  5. RFC 9114 — HTTP/3: Defines HTTP over QUIC.
  6. RFC 9000 — QUIC: Defines the QUIC transport used by HTTP/3.

Learning Resources

  • MDN Web Docs — Evolution of HTTP: Accessible historical explanation of major HTTP versions.
  • MDN Web Docs — HTTP: Practical HTTP reference for developers.
  • W3C — Information Management: A Proposal: Tim Berners-Lee's original World Wide Web proposal.
  • Cloudflare — HTTP/3: the past, the present, and the future: Operational discussion of HTTP/3 and QUIC deployment.
  • W3Techs — HTTP/2 Usage Statistics: Current website-support statistics and methodology.
  • W3Techs — HTTP/3 Usage Statistics: Current HTTP/3 website-support statistics and methodology.

Recommended Study Order

  1. Start with MDN's Evolution of HTTP for a readable overview.
  2. Use RFC 9110 for the shared meaning of HTTP methods, fields, and status codes.
  3. Compare RFC 9113 and RFC 9114 to understand why HTTP/2 and HTTP/3 use different transport designs.
  4. Use browser developer tools to inspect real requests and responses.
